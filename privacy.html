What this application does

This application is a personal integration between a self-hosted Home Assistant instance and the Google Calendar API. It is operated by a single individual for private, non-commercial household use.

Data accessed

With the account holder's explicit Google OAuth consent, this application accesses Google Calendar event data (titles, times, descriptions, and attendees where present) belonging to the authorizing Google account.

How data is used and stored

Calendar data is retrieved solely to display or act on it within the Home Assistant instance that requested access (for example, showing upcoming events on a dashboard or triggering automations). Data is stored only within that Home Assistant instance's local database and is not transmitted to any third party, sold, or used for advertising.

Data sharing

No calendar data obtained through this integration is shared with any third party. Access is limited to the Home Assistant instance operated by the account holder.

Revoking access

The account holder may revoke this application's access at any time via Google Account permissions .
