Home Assistant Google Calendar Integration

This application connects a personal, self-hosted Home Assistant instance to Google Calendar for a single household. It is not a public product, is not distributed to other users, and is not used for any commercial purpose.

The integration reads calendar event data (and, if configured, creates or updates events) so that Home Assistant automations and dashboards can display or react to calendar information.

See the privacy policy for details on how calendar data is handled.

Home Assistant is an open-source home automation platform. This page exists solely to satisfy Google Cloud Platform's OAuth consent screen branding requirements for a personal-use application.
